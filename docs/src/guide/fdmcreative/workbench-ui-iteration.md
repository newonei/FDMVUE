# 无限画布交互优化记录

适用页面：`/fdmcreative/workbench/:projectId`。包含前端交互、自动保存状态，以及工作台主动运行的执行范围和重新生成语义；保留项目角色与资产归属规则。

## 主要问题与调整

| 原有操作问题 | 现在的操作 |
| --- | --- |
| 新节点固定落在旧坐标，不易找到 | 默认在当前视野中添加并避让节点；空白处双击或 Tab 可搜索添加，支持方向键和 Enter |
| 只能逐个处理节点 | Shift 多选/框选；批量移动、复制、删除；Ctrl/Cmd+D 快速复制；整组操作一次撤销 |
| 参数、任务和助手争抢画布空间 | 统一右侧工作面板；节点库可折叠；小窗口使用可关闭的侧栏 |
| 先创建输入节点再上传，步骤较多 | 选择图片或拖入画布，上传后自动创建并绑定输入节点；支持一次撤销；每次最多 20 张、单张 25 MB |
| “试运行”“发布任务”不清楚是否真的执行 | 明确“从头运行画布/仅运行此节点/所选及下游”；发布入口改为“发布版本” |
| 跳过/取消节点导致任务结束后进度不足 | 结束进度包括成功、失败、取消、跳过、过期；失败仍明确标红 |
| 失败后不清楚如何恢复 | 显示具体失败节点，支持定位、按原任务参数重试，说明下游恢复和费用影响 |
| 查看历史任务容易混淆当前草稿 | 历史详情独立查看；定位只进入当前节点；不把历史参数覆盖到草稿 |
| 结果缩略图小、跨版本比较困难 | 历史版本折叠；任意两张有效图片并排比较、同步缩放与滚动；采用操作独立 |
| 撤销参数时可能恢复旧运行状态 | 撤销/重做只回放编辑内容，保留最新运行状态和预览，同步更新检查器 |
| 任务已提交但首次详情读取失败后失去跟踪 | 保留任务 ID、显示重连提示并自动补拉，不重复提交任务 |
| 输入名称后直接 Ctrl/Cmd+S 保存旧值 | 先提交编辑缓冲，再保存草稿 |
| 仅查看参数就触发引用绑定和模型回写 | 查看不修改草稿；编辑提示词或参考素材时才保存引用绑定，保留已有别名 |
| 上传中切换项目可能延续旧操作 | 每个异步阶段检查项目生命周期；旧批次停止，不写入新项目 |
| 串联生成只看当前任务和最近 100 条素材，分步运行后参考图预览丢失 | 从已归档输出解析图片，合并当前会话各节点的最近运行；上游完成后即可显示自动引用 |
| 待生成的连线被模型筛选当成零张参考图 | 默认模型和参数面板均按连线引用计数；不同边的同一素材仍按独立输入统计 |
| 参考图生图标为“可选”，不清楚是否必须手动选图 | 说明连线会自动传入；显示等待上游生成或已自动引用；手选作为补充入口 |
| 保存成功后 dirty 仍缓存为 true，第二次运行被保存检查拦截 | 自动保存状态始终建立响应依赖，连续编辑/保存/运行无需刷新 |
| 任务结束但节点残留生成中状态，运行按钮一直禁用 | 提交与执行状态分开；任务终态解除旧节点状态造成的锁定 |
| 单节点会重跑祖先、全画布会直接复用历史结果 | 工作台仅执行所选范围，每次主动运行重新生成；范围外读取上游已有输入 |
| 循环结果同时显示多轮图片，下游实际输入与引用预览不一致 | 单独运行下游取完整成功循环的最后一轮；该轮多张图片保留原顺序 |
| 历史重试、旧取消响应和迟到的素材页可能干扰新任务 | 提交互斥并校验正在监控的任务；素材列表只接收当前项目最新请求的响应 |

## 本地回归

在 FDMVUE 仓库根目录运行：

```powershell
pnpm --filter @vben/web-antd typecheck:fdmcreative
pnpm exec vitest run --config vitest.fdmcreative-workbench.config.ts
git diff --check
```

专用测试配置继承根配置，只统一工作台测试的 Vue 实例和 X6 依赖转换，避免 Windows 管理工作树依赖链接产生多个 Vue 实例；不改变应用构建配置。

浏览器验收覆盖节点搜索添加、图片导入与撤销、名称快捷保存、任务定位、结果跨版本比较、只读权限、运行者权限、首次详情失败后自动恢复，以及 1024/800 像素窗口布局。

连续运行验收使用真实自动保存与 SSE 处理：编辑后启动任务，同一页面先单节点成功、再单节点取消、再整图失败、再整图成功，共创建四个独立任务；节点范围为 1 个节点、整图为 6 个节点，四条事件连接均在完成后关闭。模型和任务结果仍为模拟数据。

慢响应验收另外验证：任务 9003 运行时历史任务 9002 的重试不会发起请求或抢占事件连接；取消回执挂起期间运行按钮禁用，释放后可直接启动任务 9004；其首个详情挂起时仍显示正在读取该任务并保持运行锁；任务 9005 的素材快照 5 先返回，随后释放旧快照 4，页面仍显示快照 5。三次运行在同一页面完成，无遗留事件连接或待释放响应，业务网络请求均由 fixture 模拟。

串联回归另覆盖：上游图片不在素材列表时下游仍显示引用、运行其他单节点后引用仍保留。后端新增 `CreativeConnectedImageExecutionTest`，使用真实执行输入解析和网关，验证新生成/复用历史输出都在无 `referenceAssetIds` 时自动传入模型；新增及相关测试 29 项通过。该测试不调用付费模型。

# 飞德慕业务协同平台前端

这是现有 Vue 3 / Vben / Ant Design Vue 应用内的独立业务扩展。源代码仅位于 `api/fdmplatform`、`views/fdmplatform` 与独立路由 `router/routes/modules/fdmplatform.ts`。不替换现有官方或 FDM 业务页面，不改变共享认证、请求客户端、全局样式和构建配置。

## 显式启用

默认不注册路由。部署构建环境显式设置 `VITE_FDM_PLATFORM_ENABLED=true` 后，访问 `/fdmplatform/workbench`。此为构建时开关；生产构建后变更环境变量需要重新构建。后端还需单独启用 `fdmplatform` Maven profile 和 `fdm.platform.enabled=true`，执行独立迁移并配置显式公司岗位授权。

PowerShell 示例（在前端仓库根目录执行）：

```powershell
$env:VITE_FDM_PLATFORM_ENABLED = 'true'
pnpm --filter @vben/web-antd run build
```

前端请求沿用当前 `requestClient`，业务接口基址 `/fdmplatform/v1`，由现有请求层与后端管理接口前缀整合。不新建登录页或共享 Cookie，不假设已经完成钉钉或 Keycloak SSO。

当前系统虽使用后台菜单权限模式，现有 `generateRoutesByBackend` 明确合并了 `options.routes` 与后台菜单，因此开启构建开关后会保留本扩展的本地路由，无需新增后台菜单或菜单 SQL。不要重复创建同地址菜单；平台岗位授权仍需另行配置。若此前手工配置过同地址后台入口，停用扩展时管理员应一并停用。即使残留后台菜单被访问，页面也会显示未启用且不请求任何平台 API。

## 页面能力

- 授权范围内的合同工作台、公司切换、合同与零金额样品创建 / 修订、冻结产品规格。
- 分批及超量采购申请，规则分派与人工分派，库存 / 自产 / 外采任务，报价版本和证据、采购方案、经理决策、批准范围内执行。
- 采购到货同步合格入库、异常与退货、自产人工进度和实际入库、按批准版本预留、分批发货与退货。
- 统一回款、财务到账确认、发票记录、多对多部分绑定与反向更正；成本台账、财务口径、预计与已归集订单贡献及缺项提示。
- 五类主数据映射、授权管理、采购分派规则，库存池与期初盘点、安全缓冲设置。
- 采购 AI 预审请求及结果、版本与证据、人工降级状态；读取真实 fdmai 接口结果，不伪造 AI 结论。
- 合同操作审计，以及 UTF-8 CSV 主数据迁移的文件读取、预览、预检、差异报告和确认导入。

## 访问和数据规则

先请求 `/access`，仅在取得明确公司授权后加载该范围数据。按角色请求可读取的主数据类型，动作按钮使用后端 `allowedActions`。公司切换清空旧数据并拦截旧请求的晚到结果。后端是公司 / 部门 / 本人范围、字段白名单和所有业务不变量的最终执行者。

写操作发送稳定幂等键与预期版本。库存动作同时带库存池版本与必要批准方案版本。失败保留表单与明确错误；版本变化后关闭表单、刷新单据再操作。界面金额和数量输入使用十进制字符串，正式金额由后端计算。

用户 ID 输入要求系统用户编号，不使用姓名或手机号合并身份。附件字段引用已存在的凭证 / 文件；此版本没有把输入附件编号当作完成文件上传。

## CSV 主数据迁移

UTF-8 CSV 每批 1–200 行，文件不超过 2 MB，支持标准双引号、引号转义、引号内逗号 / 换行及 UTF-8 BOM。固定表头：

```csv
type,name,code,externalId,specification,unit
```

前四列必填，`type` 为 `CUSTOMER`、`SKU`、`SUPPLIER`、`WAREHOUSE` 或 `STOCK_OWNER`。编号按文本处理，保留前导零。浏览器计算原始文件字节的 SHA-256；后端只收到映射记录与校验声明，不能据此宣称服务端已存储或验证原文件。原始备份应通过凭证引用保存。预检通过后才显示确认按钮；后端在确认时再次核对版本和已有映射，不覆盖有差异的主数据。

## 检查

在已有依赖安装的仓库根目录运行：

```powershell
pnpm exec vue-tsc --noEmit --skipLibCheck -p apps/web-antd/src/views/fdmplatform/tsconfig.check.json
```

生产构建必须显式开启上面的环境变量，确保业务路由被打包。完整业务验收还需要后端测试环境、实际角色账号和已授权主数据；编译通过不代表已完成生产联调、外部系统 SSO、历史资金库存迁移或灾备验收。

本次开发没有将界面连接真实业务测试后端，也没有向现有数据库注入演示数据。已执行限定模块 TypeScript 检查、显式启用平台的生产构建与 CSV 数据边界测试；运行环境联调仍应使用隔离数据库和经授权的验收数据。
